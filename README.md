### Hey, I'm Adi

[![Website](https://img.shields.io/badge/Website-adityarajsingh.com-0A66C2?style=flat)](https://adityarajsingh.com/)

I build MCP servers, small macOS apps, automations and homelab rigs, and run a few businesses. I write about the things I build on my blog [here](https://adityarajsingh.com/).

Most of my open-source work is fixing bugs in the self-hosted apps I actually run. If it breaks on my homelab, I send the fix upstream.
Live tracker of every PR I've opened [here](https://dev.adityarajsingh.com/#contributions).

#### Building
